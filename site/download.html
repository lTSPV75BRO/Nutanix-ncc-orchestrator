Install
From download to dashboard in four steps.
  1. 1

    Download and verify

    # x86_64; use arm64 on ARM servers
VERSION=vX.Y.Z
BASE=https://github.com/lTSPV75BRO/Nutanix-ncc-orchestrator/releases/download/$VERSION
curl -LO $BASE/ncc-v2-stack-linux-amd64.tar.gz
curl -LO $BASE/checksums.txt
sha256sum -c checksums.txt --ignore-missing
  2. 2

    Extract

    The archive holds bin/, frontend-dist/ and example_config.yaml at the top level, so give it its own folder.

    mkdir ncc && tar -xzf ncc-v2-stack-linux-amd64.tar.gz -C ncc && cd ncc
chmod +x bin/*
  3. 3

    Configure and scan

    Replace REPLACE_WITH_CLUSTER_IP in example_config.yaml, set the username, and export the secrets you use.

    export NCC_PASSWORD='your-prism-password'
./bin/ncc-orchestrator preflight-check --config example_config.yaml
./bin/ncc-orchestrator --config example_config.yaml   # one-shot scan
  4. 4

    Start the dashboard

    ./bin/ncc-orchestrator v2-start --detach --self-heal \
  --api-listen 127.0.0.1:8081 --ui-listen :8080

    Open https://localhost:8080. The first admin password is in .ncc-initial-admin-password; see v2-install-service to start at boot.

  1. 1

    Download and verify

    # Apple silicon; use darwin-amd64 on Intel Macs
VERSION=vX.Y.Z

    Extract and clear quarantine

    Binaries are not code-signed yet, so macOS quarantines them. Clear the flag for this folder only, after the checksum matched.

    mkdir ncc && tar -xzf ncc-v2-stack-darwin-arm64.tar.gz -C ncc && cd ncc
xattr -dr com.apple.quarantine .
  3. 3

    Configure and scan

    Edit example_config.yaml (clusters and username), then:

    export NCC_PASSWORD='your-prism-password'
./bin/ncc-orchestrator preflight-check --config example_config.yaml
./bin/ncc-orchestrator --config example_config.yaml
  4. 4

    Start the dashboard

    ./bin/ncc-orchestrator v2-start --detach --self-heal \
  --api-listen 127.0.0.1:8081 --ui-listen :8080

    Open https://localhost:8080 and sign in as admin with the password from .ncc-initial-admin-password.

    $Version = 'vX.Y.Z'

Verify your download
Each release has checksums.txt and a signed SLSA build-provenance attestation.
  1. 1

    Check the hash

    Stop if the result is not OK or the hashes differ.

    # Linux
sha256sum -c checksums.txt --ignore-missing
# macOS
shasum -a 256 -c checksums.txt --ignore-missing
# Windows (PowerShell)
Get-FileHash .\ncc-v2-stack-windows-amd64.zip -Algorithm SHA256
  2. 2

    Check the provenance

    With the GitHub CLI, confirm the file was built by this repository's release workflow:

    gh attestation verify ncc-v2-stack-linux-amd64.tar.gz --owner lTSPV75BRO
  3. 3

    Check the running binary

    ncc-orchestrator verify prints the version, git revision and SHA-256 of the executable.
