# Examples

| File | Use |
| --- | --- |
| [`example_config.yaml`](example_config.yaml) | Reference runner/stack config. Every option has a comment naming its CLI flag and `NCC_` environment variable. Copy it to `config.yaml` and edit. Release archives ship the same file at their top level. |
| [`example_users.yaml`](example_users.yaml) | Sample local-user seed file for the API server. |

See [`docs/FEATURES_AND_CONFIG_FLAGS.md`](../docs/FEATURES_AND_CONFIG_FLAGS.md) for every key.
